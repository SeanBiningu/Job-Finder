2. Feature 1: AI Job Matching Engine

The Problem: Token Explosion & Latency

In a production job board, a search query typically returns 25 to 50 live job listings. An average job description contains 400–800 words (600–1,000 tokens). Sending all listings to an LLM simultaneously causes context saturation, incurs ~50,000 tokens per search ($0.10–$0.25 per click), and takes 15–25 seconds of latency.

The Two-Tier Solution

  • Tier 1 (Lexical Pre-Filter & Sanitization): Sanitizes HTML, removes EEO and legal boilerplates, and computes token overlap between candidate skills/title and job listings in O(N) time. Shortlists the top 10 most relevant jobs.
  • Tier 2 (Multi-Criteria LLM Semantic Scoring): Evaluates candidate experience, career goals, and verified skills against the shortlisted 10 jobs using gpt-4o-mini.

Mathematical Suitability Scoring Rubric

Suitability Score (0-100) = (0.40 × Skills) + (0.25 × Seniority) + (0.20 × Domain) + (0.15 × WorkMode)
  • Skills Match (40%): Direct overlap of required hard skills, tools, and frameworks.
  • Seniority Alignment (25%): Match between candidate years of experience and role requirements (deducts heavily if an entry-level candidate is matched with a Senior/Staff role).
  • Domain & Role Fit (20%): Alignment of career interests, degree/education, and industry background.
  • Soft Skills & Work Mode (15%): Methodologies (Agile, Scrum), collaboration, and remote/hybrid compatibility.

3. Feature 2: AI CV Builder & Checker

Anti-Hallucination Directives

To eliminate model hallucinations, the system prompts enforce strict boundary constraints:

Strict Truthfulness Directive
1. NEVER invent degrees, certifications, companies, dates, or metrics not present in candidate input.
2. If metrics are missing, provide placeholders like [Insert % or metric] rather than guessing.
3. Enhance phrasing, structure, and professional tone, but preserve exact factual reality.

ATS Scoring Equation

Score_ATS = min(100, 50 + (5 × ActionVerbs) + (15 × QuantifiedMetrics) + (10 × LengthFitness))

XYZ Formula Bullet Rewriting

The CV engine restructures weak resume bullet points using the Google XYZ formula: "Accomplished [X], as measured by [Y], by doing [Z]."

  • Before: "Worked on React components for the checkout page."
  • After: "Engineered 12 responsive React checkout components, reducing cart abandonment by 18% through optimized state management and validation."

4. Feature 3: AI Career Assistant

Boundary Guardrails & Refusal Protocol

The Career Assistant is restricted by system instructions to employment and career development topics only:

  • Allowed Topics: Job requirement explanations, STAR behavioral interview coaching, technical screening preparation, CV advice, and salary negotiation.
  • Deflection Protocol: Non-career requests (general programming, math homework, creative fiction, politics) receive an automatic polite refusal redirecting the user back to their career goals.

Sliding-Window Context Trimmer

To avoid context window bloat and unbounded token consumption, sanitizeConversationHistory() enforces a sliding window:

Context Trimming Strategy: Retains candidate background profile + System instructions + Last 8 conversation turns (4 user turns + 4 assistant turns). This keeps prompt token counts consistently under 1,200 tokens.

5. Feature 4: AI Skills Gap Analysis

Taxonomy Prioritization

Compares candidate capabilities against real market postings, grouping gaps into three tiers:

  1. Critical Blockers: Skills demanded in ≥ 75% of postings that cause immediate resume screening rejection (e.g., SQL, TypeScript).
  2. Important Competencies: Skills required to clear technical interview rounds (e.g., State Management, API integration).
  3. Differentiators: Modern practices that set top candidates apart (e.g., CI/CD pipelines, Docker, performance profiling).

6. AI Gateway, Reliability & Security

Resilience Engineering
Production AI services must handle network dropouts, rate limits, and token overruns gracefully without crashing user interfaces.
  • Exponential Backoff: On HTTP 429 (rate limits) or 5xx server errors, the client waits 2^attempt × 1000ms + jitter and retries up to 3 times.
  • Timeout Guard: An AbortSignal.timeout(45000) ensures requests never hang indefinitely.
  • Session Caching: src/services/aiJobMatcher.js hashes the candidate profile and caches match results in sessionStorage for 10 minutes, eliminating duplicate requests when switching tabs.
  • Heuristic Fallback Engine: If OPENAI_API_KEY is absent or an upstream outage occurs, the engine dynamically falls back to an offline heuristic analyzer that returns 100% valid data contracts.
